# تطبيق عملاء مغسلة 997 (iPhone · Android · الويب)

تطبيق Expo (React Native) — كود واحد يشتغل على الآيفون والأندرويد والمتصفح. يتصل بنفس نظام المحل عبر دالة `customer-api` في Supabase.

## ماذا يقدر العميل يسوي
| الشاشة | الوظيفة |
|---|---|
| الدخول | عبر واتساب بدون كلمة سر: التطبيق يعرض رمز، العميل يرسله للمحل بضغطة، ويدخل تلقائياً |
| الرئيسية | تحية باسمه، المبلغ المتبقي أو رصيده، طلباته الحالية مع شريط المراحل، باقته، طلباته بانتظار التأكيد، أزرار سريعة |
| طلباتي | كل الطلبات ← تفاصيل الطلب: القطع (قطع الباقة بقيمتها)، الدفع، الإيصال، «وصّلوه لي البيت»، تقييم بالنجوم |
| احجز | استلام من البيت: المنطقة، العنوان أو موقعه الحالي (GPS)، اليوم والوقت، توصيل بعد التنظيف، ملاحظة |
| الأسعار | الأسعار الحية من النظام مع بحث وفلترة حسب الخدمة + الباقات وسعر القطعة + «اشترك عبر واتساب» |
| حسابي | بياناته، رصيده، باقته، اللغة (عربي/English)، التواصل مع المحل، الخروج |

كل حجز من التطبيق يظهر في صفحة التوصيل بالنظام بعلامة «📱 التطبيق» مع تنبيه في كل الصفحات، والموظف يؤكده.

## التشغيل على اللابتوب (مرة وحدة)
1. ثبّت Node.js (نسخة LTS) من nodejs.org.
2. `git clone https://github.com/jassimal3akbry/Laundry-997.git && cd Laundry-997/customer-app && npm install`
3. ثبّت تطبيق **Expo Go** على جوالك من App Store / Google Play.
4. `npx expo start` ← امسح رمز QR بكاميرا الآيفون — التطبيق يفتح على جوالك.
5. للتطوير مع Claude Code: من مجلد `Laundry-997` اكتب `claude` واطلب اللي تبيه بالعربي. ملف `CLAUDE.md` فيه كل تفاصيل المشروع.

## أوامر
| الأمر | الوظيفة |
|---|---|
| `npx expo start` | تشغيل للتطوير (Expo Go على الجوال، أو `w` للمتصفح) |
| `npx tsc --noEmit` | فحص الأخطاء |
| `npm run publish:web` | بناء نسخة الويب ونسخها لمجلد `../app` (تُنشر مع الموقع على `/app/`) |
| `npm run test:web` | اختبار نسخة الويب في متصفح آلي (بدون إنترنت — الخادم وهمي) |

## النشر في App Store و Google Play (بعد التجربة)
1. حساب Apple Developer (99$ سنوياً) — developer.apple.com — بالاسم التجاري أو الشخصي.
2. حساب Google Play Console (25$ مرة وحدة) — play.google.com/console.
3. `npm install -g eas-cli` ثم `eas login` (حساب Expo مجاني) ثم `eas build:configure`.
4. `eas build --platform ios` و `eas build --platform android` — البناء في السحابة، ما يحتاج Xcode.
5. `eas submit --platform ios` ← TestFlight للتجربة مع 5–10 عملاء، ثم المراجعة والنشر.
- المعرّف: `com.laundry997.customer` · الاسم: «997 Laundry» · الأيقونة جاهزة في `assets/`.
- Apple تطلب رابط سياسة خصوصية: https://997-laundry.github.io/privacy.html (موجود).
