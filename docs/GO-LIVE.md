# 997 Laundry — يوم التشغيل الفعلي (Go-Live)

## قبل فتح المحل (مرة واحدة)
1. **أغلق النظام على كل الأجهزة** ما عدا جهاز المالك، أو تأكد أن كل جهاز يظهر «☁ متزامن ✓».
2. Supabase ← مشروع **997 Laundry** ← SQL Editor ← New query:
   - الصق محتوى `supabase/setup.sql` ← Run ← Success.
   - New query ← الصق محتوى `supabase/golive_reset.sql` ← Run.
   - النتيجة يجب أن تكون: `owner_accounts 1`، `staff_accounts 0`، `orders 0`، `customers 0`، `next_order_number 1`.
3. **جهاز المالك:** حدّث الصفحة — الطلبات والعملاء تختفي خلال ثوانٍ، والأسعار تبقى.
4. **أضف الموظفين الحقيقيين:** الصلاحيات ← ＋ مستخدم (اسم، دور، اسم دخول) — احفظ كلمة المرور المؤقتة لكل موظف.
5. **كل جهاز للموظفين:** امسح بيانات الموقع من المتصفح (أو استخدم نافذة جديدة) ← افتح الموقع ← «☁ الدخول من السحابة» بحساب الموظف ← يغيّر كلمة المرور ← يبدأ ورديته.
6. راجع **الإعدادات ← الأسعار** و**الباقات** و**ملف المنشأة** (الاسم، الهاتف للإيصالات).
7. اضبط التاريخ والوقت على كل جهاز على «تلقائي».

## إن احتجت التراجع
Supabase ← SQL Editor ← `supabase/golive_restore.sql` ← Run — يرجع كل البيانات كما كانت قبل التصفير
(نسخة احتياطية كاملة محفوظة في `backup_997`، غير متاحة من الموقع).

## يومياً
- علامة «☁ متزامن ✓» أسفل الشاشة = كل شيء في السحابة.
- نهاية اليوم: الإقفال اليومي، ونسخة احتياطية أسبوعية (الملف الشخصي ← تصدير نسخة احتياطية).
