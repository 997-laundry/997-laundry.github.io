# مركز الأمان — 997 Laundry

القائمة الجانبية ← **🛡 مركز الأمان** (للمالك والمدير فقط — صلاحية «مركز الأمان»).

| التبويب | ما يعرضه |
|---|---|
| نظرة عامة | محاولات الدخول الفاشلة (24 ساعة)، الجلسات النشطة، التنبيهات الجديدة، حالة التحقق بخطوتين لحسابات الإدارة، **فحص سلامة السجل** |
| محاولات الدخول | كل دخول ناجح وفاشل وقفل حساب ورمز تحقق خاطئ وخروج — مع اسم المستخدم واسم الدخول والتاريخ والوقت والجهاز |
| الجلسات | كل جهاز دخل: المستخدم، الجهاز، البداية، آخر نشاط، النهاية، الحالة — وزر **«إنهاء الجلسة»** لتسجيل خروج جهاز عن بُعد |
| التغييرات الحساسة | تغيير كلمات المرور، الصلاحيات، الأسعار، الإلغاء، الحذف، العكس، الاسترداد، النسخ الاحتياطي… |
| التنبيهات | محاولات فاشلة متكررة، قفل حساب، رموز تحقق خاطئة متكررة، دخول حساب إداري من جهاز جديد، نتيجة فحص سلامة السجل |
| سجل التدقيق | كل العمليات |

البحث والتصفية في كل تبويب: **المستخدم · من تاريخ / إلى تاريخ · نوع العملية · نص حر**، وزر **تصدير CSV**.

## الحماية المفعّلة
- **تقييد المحاولات الفاشلة**: قفل الحساب مؤقتاً بعد عدد المحاولات المحدد (سياسات الأمان، افتراضياً 5 محاولات / 10 دقائق).
- **تنبيهات الدخول المشبوه**: تصل لأجهزة المالك والمدير — شارة حمراء على «مركز الأمان» ورسالة على الشاشة.
- **التحقق بخطوتين (MFA)** بتطبيق Google Authenticator / Microsoft Authenticator، ويمكن جعله **إلزامياً لحسابات الإدارة**.
- **حماية سجل التدقيق**: السحابة ترفض تعديل أو حذف أي قيد (حتى من المالك)، وكل قيد يحمل بصمة SHA-256 مرتبطة بما قبله — «فحص سلامة السجل» يكشف أي تعديل أو حذف على الجهاز.
- **إنهاء الجلسات**: خروج تلقائي بعد مدة الخمول، وعند تسجيل الخروج تُبطَل جلسة السحابة على الخادم فوراً.

## التفعيل (مرة واحدة)
1. **Supabase ← SQL Editor ← New query** ← الصق محتوى الملف `supabase/security.sql` ← **Run**.
   (يفعّل مزامنة الجلسات بين الأجهزة وزر «إنهاء الجلسة» عن بُعد. قبل تشغيله تعمل باقي المزايا، والجلسات تظهر من الجهاز نفسه فقط.)
2. **Supabase ← Authentication ← Multi-Factor (MFA)**: تأكد أن **TOTP (App Authenticator)** مفعّل (مفعّل افتراضياً).
3. **في النظام** — لكل حساب إداري: المستخدمون والصلاحيات ← سياسات الأمان ← **«تفعيل التحقق بخطوتين»** ← امسح الرمز بتطبيق المصادقة ← اكتب الرمز.
4. المالك: فعّل **«إلزام التحقق بخطوتين لحسابات الإدارة»** ← حفظ السياسات. بعدها أي مدير بدون تحقق يُطلب منه الإعداد عند دخوله.

## إذا فقدت الجوال الذي عليه تطبيق المصادقة
Supabase ← **Authentication ← Users** ← اختر الحساب ← احذف عامل MFA (Factors)، ثم في النظام فعّله من جديد.
