# تشغيل تطبيق العملاء — خطوات المالك (10 دقائق)

## 1) دالة customer-api (الخادم الخاص بالتطبيق)
1. Supabase ← مشروع المغسلة ← **Edge Functions** ← **Deploy a new function** ← **Via Editor**.
2. الاسم بالضبط: `customer-api`.
3. امسح المثال، والصق كامل محتوى `supabase/functions/customer-api/index.ts` ← **Deploy**.
4. افتح الدالة ← **Settings / Details** ← أطفئ **Verify JWT** (Enforce JWT verification) ← Save.
   (التطبيق يتحقق من العميل بنفسه عبر واتساب — مثل دالة whatsapp-bot.)
5. لا يحتاج أي Secret جديد.

## 2) تحديث مساعد واتساب
الصق أحدث `supabase/functions/whatsapp-bot/index.ts` في whatsapp-bot ← Deploy.
هذا يخليه يرد على رمز دخول التطبيق فوراً («✅ تم تأكيد دخولك»).

## 3) جرّب
1. افتح https://997-laundry.github.io/app/ على جوالك.
2. «الدخول عبر واتساب» ← يفتح واتساب برسالة فيها الرمز ← أرسلها ← ارجع للتطبيق.
3. لازم تشوف «هلا والله …» وطلباتك.
4. احجز استلام ← افتح النظام ← يظهر تنبيه «📲 طلب من التطبيق» وفي صفحة التوصيل بطاقة «📱 التطبيق».

## 4) وصّله للعملاء
- اطبع ملصق الكاونتر (QR) وحطه عند الكاشير.
- أضف الرابط في بايو انستقرام وفي رسالة الترحيب بواتساب.
- للآيفون: الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية» = أيقونة مثل التطبيق.

## 5) لاحقاً: App Store / Google Play
راجع `customer-app/README.md` (حساب Apple 99$/سنة، Google 25$ مرة وحدة، البناء بـ EAS في السحابة).
